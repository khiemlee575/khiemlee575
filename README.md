## 🚀 Dự án tiêu biểu

### 1. Humify – HRM & Agile Management Platform

**Tech Stack:** Java, Spring Boot, Spring Security, PostgreSQL, Vue.js, ESP32/NFC, RESTful APIs

Nền tảng hỗ trợ quản lý nhân sự, chấm công, tính lương và theo dõi công việc theo phương pháp Agile.

- Tham gia phát triển các API phục vụ quản lý dữ liệu chấm công và yêu cầu điều chỉnh chấm công.
- Phát triển module quản lý ca làm việc và theo dõi trạng thái chấm công.
- Tham gia xây dựng các chức năng quản lý Sprint, bình luận công việc và chức vụ.
- Làm việc với dữ liệu hiệu suất và KPI dựa trên thông tin công việc, chấm công.

### 2. Sneaker Store

**Tech Stack:** Java, Spring Boot, Spring Security, MySQL, PayOS, Vue.js

Website thương mại điện tử bán giày với các chức năng xử lý đơn hàng và thanh toán trực tuyến.

- Phát triển API và xử lý nghiệp vụ cho module OrderItem.
- Thiết kế bảng dữ liệu và quan hệ giữa các entity phục vụ xử lý đơn hàng.
- Tích hợp PayOS API cho quy trình thanh toán.
- Kết nối API backend với giao diện frontend.

### 3. Laptop E-Commerce

**Tech Stack:** Java, Spring Boot 3, MySQL, Thymeleaf, Bootstrap 5

Ứng dụng thương mại điện tử hỗ trợ quản lý sản phẩm laptop và tài khoản người dùng.

- Tham gia phát triển ứng dụng theo mô hình MVC và kiến trúc ba tầng.
- Xây dựng các API CRUD cho module Brand.
- Tham gia triển khai chức năng đăng ký, đăng nhập và khôi phục mật khẩu.
- Thiết kế cơ sở dữ liệu quan hệ và thực hiện các thao tác dữ liệu.
